Личный сервис для владельца и приглашённых пользователей. Контакт по вопросам данных и удаления: arithmeticg@gmail.com.

Данные и цели

Обрабатываются отправленные сообщения и файлы, email аккаунта и разрешённые сведения календаря, почты, проектов и документов — только для запрошенных функций. Google Диск использует право drive.file для файлов приложения. Подключения и данные пользователей разделены.

Обработка и передача

Для работы используются Telegram, Google/Яндекс, Supabase и API OpenAI. Необходимые данные запроса и календаря могут передаваться ИИ для ответа. Входящие письма показываются без передачи ИИ; текст, отправленный пользователем вручную, обрабатывается как его запрос. Данные Google не продаются, не используются для рекламы или обучения общих моделей ИИ. Их использование соответствует Google API Services User Data Policy, включая Limited Use.

Доступ и хранение

По умолчанию документы приватны. Открытая ссылка даёт чтение любому её обладателю; доступ по email — указанному аккаунту. Создание проектов, публикация документов и отправка писем требуют подтверждения. Сохранённые записи и файлы хранятся до запроса удаления. Разрешение Google можно отозвать в настройках аккаунта; ранее сохранённые данные удаляются отдельным запросом на контактный email.

Информационный сайт размещён на GitHub Pages; технические данные посетителей обрабатываются по политике GitHub.
