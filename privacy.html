Политика конфиденциальности

Редакция от 13 ноября 2026 года. Применяется к Помощник и подключённым к нему личным Telegram-помощникам.

1. Сервис и контакт

Помощник предназначен для владельца и ограниченного круга лично знакомых пользователей. По вопросам доступа, обработки и удаления данных обращайтесь к владельцу: arithmeticg@gmail.com.

2. Какие данные обрабатываются

Помощник обрабатывает идентификаторы пользователя и чата Telegram, сообщения, голосовые записи, фотографии и документы, которые пользователь отправляет в сервис. По запросу сохраняются личные заметки, проекты, задачи, расходы и связанные записи. Для подключения Google используются email аккаунта, подтверждение его принадлежности и выданные Google токены авторизации.

В зависимости от отдельно предоставленных разрешений сервис получает:

  • Google Календарь: список доступных календарей, события, названия, даты и время, место и описание при работе с событием, сведения об организаторе и участниках, статусы ответа, ссылки на событие и видеовстречу.
  • Gmail: сведения о письмах, включая отправителя, получателя, тему, дату и текст выбранных входящих; данные подготовленного исходящего письма. Вложения входящих писем текущая функция чтения не загружает пользователю.

Права календаря не означают выдачу прав Gmail. У каждого аккаунта используется собственное подключение; права владельца сервиса не передаются другим пользователям ботов.

3. Для чего используются данные Google

Данные календаря нужны для ответов на запросы пользователя, проверки занятости, создания и изменения событий, приглашения явно указанных участников и выбранных уведомлений. Удаление события Google выполняется по запросу пользователя. Автоматическая служба уведомлений читает календарь и не создаёт и не удаляет события.

Данные Gmail нужны для показа входящих по запросу и подготовки/отправки письма выбранному получателю. Исходящее письмо отправляется после полного предпросмотра и отдельного подтверждения кнопкой в Telegram. Функция чтения Gmail не удаляет письма и не меняет их флаги.

4. Обработка искусственным интеллектом

Для ответов, разбора сообщений, голоса и документов используется API OpenAI. При выполнении календарной просьбы необходимые сведения о событиях могут передаваться модели для подготовки ответа. Тексты писем, прочитанные через функцию входящей почты, выводятся в чат без передачи модели и не добавляются в обычную историю диалога. Если пользователь сам отправит текст письма сообщением, он обрабатывается как текст пользовательского запроса.

Сервис не использует данные Google для обучения общих моделей искусственного интеллекта. Данные Google не продаются, не используются для рекламы и передаются только в объёме, необходимом для запрошенных пользователем функций. Использование данных Google ограничено описанными здесь функциями и Google API Services User Data Policy, включая требования Limited Use.

5. Хранение и поставщики инфраструктуры

Серверный код, база записей и история диалогов работают на инфраструктуре Supabase; пользовательские оригиналы документов хранятся в закрытом файловом хранилище. Для календарных уведомлений хранятся технические состояния синхронизации, необходимые сведения о событиях и журнал доставки. Черновики и результаты работы помощника могут содержать данные, которые пользователь попросил обработать или сохранить.

Токены Google хранятся в закрытых серверных настройках; при подключении и обслуживании также используются закрытые локальные файлы на устройстве владельца. Значения токенов не публикуются на этой странице и не выдаются пользователям чата. Сохранённые записи защищены проверками разрешённого пользователя и правами доступа к базе и хранилищу.

Telegram передаёт сообщения и показывает результаты, включая уведомления календаря и предпросмотр писем. Google выполняет календарные и почтовые операции. Supabase предоставляет серверную инфраструктуру, OpenAI — обработку запросов в описанных выше случаях. У каждого поставщика также действуют собственные условия обработки данных.

Публичные информационные страницы размещены на GitHub Pages. GitHub журналирует IP-адреса посетителей для безопасности в соответствии со своей политикой конфиденциальности. На этих страницах нет формы подключения Google, пользовательских календарей, содержимого писем или встроенных аналитических счётчиков.

Проекты и документы PM

При отдельном разрешении сервис создаёт проекты и задачи в Яндекс Трекере, а также документы на Google Диске и в папке приложения Яндекс Диска. Перед выполнением пользователь видит полный текст, исполнителей, сроки и выбранный режим доступа и подтверждает действие.

Google Диск подключается с правом drive.file для файлов, созданных или выбранных через приложение. По умолчанию документы приватны. Открытая ссылка доступна любому её обладателю; доступ по указанному email предоставляется через Google Диск с правом чтения. Публикация и изменение доступа требуют подтверждения пользователя.

6. Доступ других людей

Личные данные одного пользователя не становятся доступными другим членам семьи только из-за использования этого сервиса. Указанные пользователем участники встречи получают предусмотренные календарём сведения о встрече. Получатели писем получают подтверждённое пользователем письмо. Техническая работа с личными данными при обслуживании выполняется в рамках разрешённой пользователем задачи; сервис не предоставляет посторонним публичный доступ к истории и файлам.

7. Срок хранения и удаление

Сохранённая история и личные записи не удаляются автоматически по истечении фиксированного срока. Для удаления выбранных данных и отключения подключения направьте запрос на arithmeticg@gmail.com с указанием аккаунта и объёма удаления; при необходимости владелец проверит принадлежность аккаунта. Не отправляйте пароли и токены. Запросы обрабатываются владельцем сервиса, автоматическая кнопка удаления всех данных пока не реализована.

Команда /start начинает новый контекст переписки, но не удаляет сохранённую личную базу. Отзыв разрешения в аккаунте Google прекращает доступ по этому разрешению; для удаления ранее сохранённых в сервисе данных нужен отдельный запрос. Удаление сообщений из Telegram и данных у других поставщиков регулируется их настройками и политиками.

8. Изменения

При изменении фактических функций или обработки данных политика обновляется с новой датой. Дополнительные права Google предоставляются через отдельный экран согласия Google, а не только за счёт изменения этого текста.
